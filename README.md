# LAPTOPS

A premium showcase of flagship laptops from around the world — 28 legendary machines from 9 countries, presented as a dark editorial gallery.

**Live:** https://laptops.vercel.app/

- Static site: `index.html` + `styles.css` + `app.js`
- Country sections, search, country/category filters, spec detail modals
- No build step — deploys straight to Vercel
